# Known limitations — v0.2.0 source-only

1. No new full Core v2/L4b WSLC certificate. A real eight-call Codex smoke proved
   its bounded ALPHA/readback/native image/renderer/normal App cleanup scope;
   it did not execute the fixed full public Script/Core recipe.
2. Codex0.164.0-alpha.11.1 was observed terminating an owned MCP Job with status1
   at client close. Direct MCP EOF0 is different. No arbitrary failure is
   converted to success, and normal App exit is never inferred from PID absence.
3. Persistent canary exposure stays five read-only tools. Mutable actions are
   only for individually approved owned fixtures after identity/focus/lease/
   cancellation/postcondition/normal-shutdown gates. No full multi-agent mutable,
   generic foreign-app, two-WSLC-session or production rollout claim.
4. Existing registry cleanup rejects an oversized registry. This blocker is
   retained; no truncation, unsafe deletion or raised guard is shipped here.
5. Storagev1.1 is monitored software enforcement, not hard quota. The120GB
   decimal ceiling does not cap shared VM/image/cache/VHDX storage. Actual
   unknown ownership/usage, unexpected mounts or low SSD reserve refuse growth;
   refused growth must still permit normal quit and owned cleanup.
6. WSLC targets one approved FocusFixture71 payload/owner context. Bootstrap,
   upload and ownership helpers are included, but the approved application ELF,
   source/build bundle, image/provisioning authority and ModuleShell payload are
   not. This is not turnkey arbitrary Linux application execution.
7. Native `/g` capture is required for Remote GPU evidence; an OS capture is not
   substituted. NVIDIA/D3D12 qualification is environment-specific. An earlier
   recovery attempt saw AMD and was correctly refused; the later3F18 smoke
   observed NVIDIA. Neither result predicts another host's GPU selection.
8. The canonical router is not this frozen package router. Only this package's
   exact implementation hashes are published. New documentation/metadata does
   not recertify a freshly rebuilt executable or another source root.
9. Existing HTTP/UIA/stdio sources and scoped tests are not complete new-source
   COM/cancellation/abrupt-child-loss compatibility acceptance. Unsupported
   operations refuse; no silent fallback to another input mechanism.
10. Linux semantic SetValue and the typed app semantic module's native producer
    are not accepted implementations. Button projection, DropDown, CheckBox,
    multiline, scroll/reveal and canvas/pick are outside the typed module scope.
11. Optional ModuleShell profile tests include operator-only fixtures not bundled
    here. Their absence remains a refusal/NOT_RUN, not a unit PASS. The full
    synthetic provenance suite is kept separately from cheap source CI; it
    does not prove real Linux/GUI acceptance either.

No private runtime receipts, credentials, user documents, images/VHDX or Makepad
vendor are included. No binary artifact is represented as clean-build qualified.

Publication privacy delta: bootstrap-runtime.ps1, upload-artifact.ps1 and their
source contract test use a neutral /opt/makepad-operator staging root. This is
not byte-equivalent to the private compiled resource layout. Rust MCP and its
embedded runtime Python are unchanged, but the public provisioning variant
requires fresh approved profiles/artifacts and actual E2E before use. Do not
reuse the historical3F18 WSLC certificate or substitute paths silently.
